# Aether Launcher

Стильный и быстрый лаунчер для Minecraft Java Edition на Android.  
Создан на базе [Zalith Launcher](https://github.com/ZalithLauncher/ZalithLauncher) и [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher).

## Благодарности
Огромное спасибо разработчикам **PojavLauncher** и **Zalith Launcher** за их невероятный труд.  
Этот проект распространяется под лицензией GPL v3, унаследованной от оригинальных проектов.

## Особенности
- Уникальный тёмно-золотой интерфейс в стиле Aether
- Лёгкие оптимизации для более быстрого запуска и плавной работы
- Поддержка офлайн-аккаунта (игра без интернета и пароля)
- Встроенная ссылка на сообщество AetherMods

## Сообщество
Присоединяйся к нашему Telegram-каналу: [AetherMods](https://t.me/AetherMods)

## Установка
1. Скачай последний APK в разделе [Releases](https://github.com/letov7482/AetherLauncher/releases)
2. Установи его на свой телефон
3. Запусти и играй!
